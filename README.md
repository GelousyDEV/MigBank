# MigBank

MigBank é um aplicativo de simulação bancária para crianças, criado para brincar de:
- abrir conta
- fazer login
- depositar dinheiro fictício
- sacar dinheiro fictício
- pagar no mercadinho
- usar PIX simulado
- registrar compras no caixa

## Descrição

Este projeto não é um banco real e não usa dinheiro verdadeiro.  
Ele foi criado como uma brincadeira educativa para simular operações bancárias simples em um ambiente infantil.

## Funcionalidades

- Cadastro de usuário
- Login de conta
- Ver saldo
- Depositar dinheiro fictício
- Sacar dinheiro fictício
- Mercado com produtos e preços
- Carrinho de compras
- Caixa da loja
- Escolha de pagamento
- Simulação de PIX
- Histórico de compras

## Como funciona

A criança cria uma conta no aplicativo e recebe um saldo inicial fictício.
Depois ela pode:
- comprar itens do mercadinho
- fazer depósitos
- sacar dinheiro
- pagar com PIX simulado
- fazer compras no caixa

Tudo é apenas para brincadeira e aprendizagem.

## Como executar

1. Abra o arquivo `main.py`
2. Execute com Python:
```bash
python main.py
```

## Exemplo de uso

```python
print("Bem-vindo ao MigBank!")
```

## Observação

Este projeto é uma simulação, para uso educativo e recreativo.  
Não representa um banco real, não realiza transações financeiras reais e não deve ser usado como sistema financeiro oficial.
